1.2 Dashboard - Cards Estatísticos

Total de Estudantes

SELECT COUNT(*) as total FROM estudantes
Objetivo: Contar número total de estudantes cadastrados
Localização: DashboardService.getTotalEstudantes()
Tela: Dashboard - Card "Total de estudantes"

Livros Disponíveis

SELECT SUM(unidades) as total FROM livros WHERE status = 'Disponível' AND unidades > 0
Objetivo: Somar unidades de livros disponíveis
Localização: DashboardService.getLivrosDisponiveis()
Tela: Dashboard - Card "Livros Disponíveis"

Empréstimos Ativos

SELECT COUNT(*) as total FROM emprestimos WHERE data_devolucao_real IS NULL
Objetivo: Contar empréstimos sem data de devolução
Localização: DashboardService.getEmprestimosAtivos()
Tela: Dashboard - Card "Empréstimos Ativos"

Multas Pendentes

SELECT SUM(valor_multa) as total FROM emprestimos WHERE pago = 0 AND valor_multa > 0
Objetivo: Somar multas não pagas
Localização: DashboardService.getMultasPendentes()
Tela: Dashboard - Card "Multas Pendentes"

1.3 Dashboard - Listas e Gráficos

Últimos Empréstimos

SELECT e.id_emprestimo, est.nome as estudante_nome, l.titulo as livro_titulo,
e.data_saida, e.data_prevista_devolucao, e.data_devolucao_real
FROM emprestimos e
JOIN estudantes est ON e.fk_estudante = est.id_estudante
JOIN livros l ON e.fk_livro = l.id_livro
ORDER BY e.data_saida DESC LIMIT 5
Objetivo: Listar os 5 empréstimos mais recentes
Localização: DashboardService.getUltimosEmprestimos()
Tela: Dashboard - Lista "Últimos Empréstimos"

Top Livros Mais Emprestados

SELECT l.titulo, COUNT(e.id_emprestimo) as total_emprestimos
FROM livros l
JOIN emprestimos e ON l.id_livro = e.fk_livro
GROUP BY l.id_livro
ORDER BY total_emprestimos DESC LIMIT 5
Objetivo: Ranking dos livros mais populares
Localização: DashboardService.getTopLivros()
Tela: Dashboard - Lista "Top Livros"

Gráfico de Empréstimos por Mês

SELECT MONTH(data_saida) as mes, COUNT(*) as total
FROM emprestimos
WHERE YEAR(data_saida) = YEAR(CURDATE())
GROUP BY MONTH(data_saida)
ORDER BY mes
Objetivo: Dados para gráfico de barras mensal
Localização: DashboardService.getEmprestimosPorMes()
Tela: Dashboard - Gráfico

1.4 CRUD - Estudantes

Listar Todos os Estudantes

SELECT * FROM estudantes ORDER BY nome
Objetivo: Carregar tabela com todos estudantes
Localização: EstudanteDAO.listarTodos()
Tela: Gestão de Estudantes (TableView)

Buscar por Nome (Busca Parcial)

SELECT * FROM estudantes WHERE nome LIKE ? ORDER BY nome
Objetivo: Filtrar estudantes pelo nome
Localização: EstudanteDAO.buscarPorNome()
Tela: Gestão de Estudantes (Campo de busca)

Buscar por Cartão RFID

SELECT * FROM estudantes WHERE id_cartao_arduino = ?
Objetivo: Encontrar estudante pelo cartão
Localização: EstudanteDAO.buscarPorCartaoArduino()
Tela: Empréstimos (leitor RFID)

1.5 CRUD - Livros

Listar Todos os Livros

SELECT l.*, d.nome_disciplina FROM livros l
LEFT JOIN disciplinas d ON l.fk_disciplina = d.id_disciplina
ORDER BY l.titulo
Objetivo: Carregar tabela de livros com disciplina
Localização: LivroDAO.listarTodos()
Tela: Gestão de Livros (TableView)

Buscar Livro por ISBN

SELECT l.*, d.nome_disciplina FROM livros l
LEFT JOIN disciplinas d ON l.fk_disciplina = d.id_disciplina
WHERE l.isbn = ?
Objetivo: Buscar livro pelo código ISBN
Localização: LivroDAO.buscarPorIsbn()
Tela: Empréstimos (busca rápida)

Buscar Livro por Título (Busca Parcial)

SELECT l.*, d.nome_disciplina FROM livros l
LEFT JOIN disciplinas d ON l.fk_disciplina = d.id_disciplina
WHERE l.titulo LIKE ? ORDER BY l.titulo
Objetivo: Filtrar livros por título
Localização: LivroDAO.buscarPorTitulo()
Tela: Gestão de Livros (campo de busca)

1.6 CRUD - Empréstimos

Empréstimos Ativos por Estudante

SELECT * FROM emprestimos
WHERE fk_estudante = ? AND data_devolucao_real IS NULL
ORDER BY data_saida DESC
Objetivo: Listar empréstimos em andamento de um estudante
Localização: EmprestimoDAO.listarAtivosPorEstudante()
Tela: Empréstimos (tabela de empréstimos ativos)

Empréstimos com Atraso

SELECT * FROM emprestimos
WHERE data_devolucao_real IS NULL AND data_prevista_devolucao < CURDATE()
Objetivo: Identificar empréstimos vencidos
Localização: EmprestimoDAO.listarEmprestimosAtrasados()
Tela: Relatórios, Alertas

Verificar Multa Pendente do Estudante

SELECT COUNT(*) FROM emprestimos
WHERE fk_estudante = ? AND pago = 0 AND valor_multa > 0
Objetivo: Impedir novos empréstimos com multa
Localização: EmprestimoDAO.temMultaPendente()
Tela: Empréstimos (antes de novo empréstimo)

3. ATUALIZAÇÕES (UPDATE)

3.1 Atualizar Estudante

UPDATE estudantes SET nome = ?, curso = ?, id_cartao_arduino = ?, idade = ?, departamento = ?, codigo_estudante = ?
WHERE id_estudante = ?
Localização: EstudanteDAO.atualizar()
Tela: Gestão de Estudantes (Botão Atualizar)

3.2 Atualizar Unidades do Livro (Após Empréstimo/Devolução)

UPDATE livros SET unidades = ?, status = ? WHERE id_livro = ?
Localização: LivroDAO.atualizarUnidades()
Tela: Empréstimos (após empréstimo/devolução)
Regra: Status muda para "Indisponível" se unidades = 0

3.3 Registrar Devolução

UPDATE emprestimos SET data_devolucao_real = ?, valor_multa = ?, pago = ?
WHERE id_emprestimo = ?
Localização: EmprestimoDAO.registrarDevolucao()
Tela: Empréstimos (Botão "Realizar Devolução")

3.4 Pagar Multa

UPDATE emprestimos SET pago = 1 WHERE id_emprestimo = ?
Localização: EmprestimoDAO.pagarMulta()
Tela: Relatórios/Financeiro

4. EXCLUSÕES (DELETE)

4.1 Deletar Estudante

DELETE FROM estudantes WHERE id_estudante = ?
Localização: EstudanteDAO.deletar()
Tela: Gestão de Estudantes (Botão Deletar)
Regra: Verifica empréstimos ativos antes de deletar

4.2 Deletar Livro

DELETE FROM livros WHERE id_livro = ?
Localização: LivroDAO.deletar()
Tela: Gestão de Livros (Botão Deletar)
Regra: Verifica empréstimos ativos antes de deletar

5. TRANSAÇÕES (Commit/Rollback)

5.1 Empréstimo (Transação com 2 operações)

-- Operação 1: Inserir empréstimo
INSERT INTO emprestimos (fk_estudante, fk_livro, data_saida, data_prevista_devolucao, valor_multa, pago)
VALUES (?, ?, ?, ?, ?, ?)

-- Operação 2: Atualizar unidades do livro
UPDATE livros SET unidades = ?, status = ? WHERE id_livro = ?
Localização: EmprestimoDAO.inserir()
Tela: Empréstimos
Regra: Se uma operação falhar, tudo é desfeito (ROLLBACK)

5.2 Devolução (Transação com 2 operações)

-- Operação 1: Registrar devolução
UPDATE emprestimos SET data_devolucao_real = ?, valor_multa = ?, pago = ? WHERE id_emprestimo = ?

-- Operação 2: Devolver unidade do livro
UPDATE livros SET unidades = ?, status = ? WHERE id_livro = ?
Localização: EmprestimoDAO.registrarDevolucao()
Tela: Empréstimos (Botão "Realizar Devolução")

9. REGRAS DE NEGÓCIO IMPLEMENTADAS NO SQL

  • Status do livro atualiza automaticamente quando unidades = 0
  • Multa calculada automaticamente baseada em dias de atraso (R$ 2,00/dia)
  • Limite de 3 empréstimos ativos por estudante
  • Não permite empréstimo com multa pendente
  • Não permite deletar registro com dependências ativas
  • UNIQUE KEY impede duplicação (ISBN, código estudante, cartão RFID)

10. DIAGRAMA DO BANCO DE DADOS

Tabelas do Sistema

  • usuarios - id_usuario, nome, usuario, senha, tipo, foto, ativo, data_cadastro
  • disciplinas - id_disciplina, nome_disciplina
  • livros - id_livro, titulo, autor, ano_publicacao, isbn, status, categoria, unidades, fk_disciplina
  • estudantes - id_estudante, nome, curso, id_cartao_arduino, data_cadastro, idade, departamento, codigo_estudante
  • emprestimos - id_emprestimo, fk_estudante, fk_livro, data_saida, data_prevista_devolucao, data_devolucao_real, valor_multa, pago

Relacionamentos

  • livros.fk_disciplina → disciplinas.id_disciplina
  • emprestimos.fk_estudante → estudantes.id_estudante
  • emprestimos.fk_livro → livros.id_livro
